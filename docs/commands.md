# Command Reference / 训练命令速查

> 以下命令中的缓存目录 `cache_patches`、输出目录 `pretrain_vae/`、`results_latent/`、`results_auto_best/`
> 均为相对路径，会在运行时自动创建。数据集路径由环境变量 `HSI_DATASET_ROOT` 控制，默认 `./datasets`。

 ┌───────────────────┬─────────────────────────────────────────────────────────────────────────────────────────┐                               
 │ 参数              │ 含义                                                                                    │                               
 ├───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────┤                               
 │ -d / --dataset    │ 选择哪个高光谱数据集，可选：LongKou, PU, Houston, IP, Salinas, KSC, Botswana, HongHu 等 │                               
 ├───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────┤                               
 │ --n-pc            │ PCA 降维保留的主成分数，例如 16 表示把几百个波段压缩到 16 个通道                        │                               
 ├───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────┤                               
 │ --patch-size      │ 从图像上裁剪的 patch 大小，32 表示 32×32 像素的方块                                     │                               
 ├───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────┤                               
 │ --label-condition │ 提取哪些像素的 patch：all（全部）、!=0（只取有标签的地物）、==0（只取背景）             │                               
 ├───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────┤                               
 │ --no-processing   │ 加上此标志则跳过 PCA 降维，直接使用原始波段数                                           │                               
 ├───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────┤                               
 │ --whiten          │ PCA 是否做白化（让各主成分方差为 1），默认开启                                          │                               
 └───────────────────┴─────────────────────────────────────────────────────────────────────────────────────────┘                               
                                                                                                                                               
 ────────────────────────────────────────────────────────────────────────────────                                                              
                                                                                                                                               
 ### 数据加载参数                                                                                                                              
                                                                                                                                               
 ┌───────────────┬────────────────────────────────────────────────────────┐                                                                    
 │ 参数          │ 含义                                                   │                                                                    
 ├───────────────┼────────────────────────────────────────────────────────┤                                                                    
 │ --batch-size  │ 每次迭代送入 GPU 的样本数，越大越吃显存但训练越快      │                                                                    
 ├───────────────┼────────────────────────────────────────────────────────┤

 └───────────────┴────────────────────────────────────────────────────────┘

 ### 模型架构参数                                                                                                                              
                                                                                                                                               
 ┌──────────────────────┬────────────────────────────────────────────────────────────────────────────────────────┐                             
 │ 参数                 │ 含义                                                                                   │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --latent-channels    │ 潜在空间（latent space）的通道数，越大表示压缩后的信息容量越大                         │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --block-out-channels │ 每层编码器/解码器的输出通道数，逗号分隔，如 32,64 表示第 1 层 32 通道、第 2 层 64 通道 │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --layers-per-block   │ 每个 block 里堆叠的 ResNet 层数，越大模型越深                                          │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --num-down-blocks    │ 下采样/上采样的次数，2 表示降采样 2 次（图像缩小 4 倍）                                │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --norm-num-groups    │ GroupNorm 的分组数，通常设为 16 或 32                                                  │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --no-mid-attention   │ 加上此标志则去掉中间的 Attention 层（节省显存）                                        │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --act-fn             │ 激活函数，默认 silu（Swish），也可用 relu、gelu 等                                     │                             
 ├──────────────────────┼────────────────────────────────────────────────────────────────────────────────────────┤                             
 │ --scaling-factor     │ 潜在空间的缩放系数，扩散模型中常用 0.18215，这里 VAE 预训练设为 1.0                    │                             
 └──────────────────────┴────────────────────────────────────────────────────────────────────────────────────────┘                             
                                                                                                                                               
 ────────────────────────────────────────────────────────────────────────────────                                                              
                                                                                                                                               
 ### 损失函数权重                                                                                                                              
                                                                                                                                               
 ┌─────────┬───────────────────────────────────────────────────────────────────────────┐                                                       
 │ 参数    │ 含义                                                                      │                                                       
 ├─────────┼───────────────────────────────────────────────────────────────────────────┤                                                       
 │ --alpha │ MSE 重建损失的权重，控制像素级还原程度                                    │                                                       
 ├─────────┼───────────────────────────────────────────────────────────────────────────┤                                                       
 │ --beta  │ KL 散度损失的权重，控制潜在空间的规则性（值越小重建越精准但 latent 越乱） │                                                       
 ├─────────┼───────────────────────────────────────────────────────────────────────────┤                                                       
 │ --gamma │ SAM（光谱角度）损失的权重，控制光谱曲线的相似度，对高光谱数据很重要       │                                                       
 └─────────┴───────────────────────────────────────────────────────────────────────────┘                                                       
                                                                                                                                               
 总损失公式：Loss = α × MSE + β × KL + γ × SAM                                                                                                 
                                                                                                                                               
 ────────────────────────────────────────────────────────────────────────────────                                                              
                                                                                                                                               
 ### 训练参数                                                                                                                                  
                                                                                                                                               
 ┌──────────────────────┬────────────────────────────────────────────────┐                                                                     
 │ 参数                 │ 含义                                           │                                                                     
 ├──────────────────────┼────────────────────────────────────────────────┤                                                                     
 │ -e / --epochs        │ 训练总轮数，一轮 = 所有样本过一次              │                                                                     
 ├──────────────────────┼────────────────────────────────────────────────┤                                                                     
 │ --lr                 │ 学习率，Adam 优化器的初始步长                  │                                                                     
 ├──────────────────────┼────────────────────────────────────────────────┤                                                                     
 │ --seed               │ 随机种子，设固定值可复现结果                   │                                                                     
 ├──────────────────────┼────────────────────────────────────────────────┤                                                                     
 │ --device             │ 训练设备，cuda:0 用第一张 GPU，cpu 用 CPU      │                                                                     
 ├──────────────────────┼────────────────────────────────────────────────┤                                                                     
 │ --grad-clip          │ 梯度裁剪的最大范数，防止梯度爆炸，0 表示不裁剪 │                                                                     
 ├──────────────────────┼────────────────────────────────────────────────┤                                                                     
 │ --scheduler-factor   │ 学习率衰减因子，loss 不下降时 lr 乘以这个数    │                                                                     
 ├──────────────────────┼────────────────────────────────────────────────┤                                                                     
 │ --scheduler-patience │ 学习率衰减的耐心值，连续多少轮 loss 不降才衰减 │                                                                     
 └──────────────────────┴────────────────────────────────────────────────┘
